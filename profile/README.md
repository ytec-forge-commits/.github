# Y-TEC Forge

> **アイデアを、動くものへ。**  
> *Ideas into things that move.*

Y-TEC Forge は、便利さとワクワクをコードから生み出す制作拠点です。  
Windows アプリ、ツール、ブラウザゲーム、オープンソースプロジェクトを育てています。

Y-TEC Forge is a creative technology workshop for useful and playful software.  
We build Windows apps, tools, browser games, and open-source projects.

## Explore

- [Y-TEC Forge](https://ytec.cloudfree.jp/forge/) — 作品紹介、更新情報、制作の背景
- [Projects](https://ytec.cloudfree.jp/forge/projects/) — アプリ、ツール、ゲーム、OSS
- [Open Source](https://ytec.cloudfree.jp/forge/open-source/) — 公開中のソースコード

## What we value

**YOUR TECHNICAL EXCELLENCE & CREATIVITY**

Y-TEC の Y は **Your**。技術や創造を、使う人へ届けるために。  
そしてもうひとつの Y は **Why?**。小さな疑問と好奇心から、ものづくりを始めます。

The Y in Y-TEC means both **Your** and **Why?**.  
We make with care for the people who use our work, and begin every creation with curiosity.

**Every Y begins with “Why?”**
